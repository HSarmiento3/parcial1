# parcial1
Este es un proyecto de un sistema de ventas y de inventario
El sistema tiene las siguientes opciones:
1. Registrar un producto nuevo: Pide el nombre del producto, el precio y la cantidad
2. Consultar el inventario: Muestra en pantalla una lista de todos los productos que se registraron
3. Registrar venta: Te pide un producto y la cantidad que vas a vender, luego de eso se calcula el precio con iva y descuento.
Al final muestra como un recibo con el total de todo.
4. Reporte y estadísticas: Muestra la cantidad de ventas realizadas, el dinero ganado y el promedio, junto con el producto mas vendido
5. Salir: Finaliza y cierra todo

Para ejecutarlo se necesita tener .NET SDK, para abrirlo se usa cmd
Se escribe cd parcial1 y luego dotnet run, entonces aparecera el menu del programa
